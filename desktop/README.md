# Jarvis PC

Windows-Fenster, mit dem das Handy den Rechner live steuert. Kein altes Python-Backend, keine NAS.

## Start

1. Auf dem **Windows-PC** `desktop/JarvisPC.bat` doppelklicken (Fenster bleibt offen).
2. IP und Token aus dem Fenster notieren.
3. Handy: Jarvis → Einstellungen → **PC** → IP, Port `18790`, Token, Schalter an → **PC testen**.
4. Gleiches WLAN. Windows-Firewall darf Port 18790 nicht blocken.

## Stimme

- `FIFA starten`
- `Was siehst du auf dem PC` (Screenshot; Vorlesen braucht Gemini)
- `klick Mitte` / `Maus nach rechts` / `Züge anklicken` (Klick auf sichtbares Element: Gemini)
- `Zeig Ordner Downloads` / `Lege Ordner Desktop\Test an`
- Löschen erst nach `Ja`

Ohne laufende App sagt Jarvis das ehrlich. Kein erfundenes FIFA, kein erfundener Bildschirminhalt.
