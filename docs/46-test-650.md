## Lücken — naive Nutzer

Ein Nutzer, der nicht weiß was Jarvis kann, landet oft im **Plaudern** (`llm`). Ohne Key: „Kein Hirn…“. Mit Gemini: freie Antwort, kein Katalog.

| Prompt | Heute | Soll |
|--------|-------|------|
| `Was kannst du?` / `Was kannst du denn so?` / `Womit kannst du helfen?` | llm | `help` (derselbe Katalog wie `/hilfe`) |
| `Bist du ChatGPT?` / `Bist du eine KI?` | llm | smalltalk, ehrlich: Jarvis auf dem Handy, Gemini wenn Key |
| `Kannst du Bilder malen?` / `Öffne Instagram` / `Bestell Pizza` | llm | refuse, ein Satz, kein Fake |
| `Rufe 112` | llm | refuse (Notruf nicht still starten) |
| `Schreib mir eine E-Mail` | **maps** (SMS-Parser frisst `schreib mir`) | refuse: kein Mail-Tool |
| `Wie komme ich nach Hause` | llm | drive / maps wie `Fahr mich nach Hause` |
| `Mach ein Foto` | llm | refuse: Foto-Knopf, kein Kamera-Befehl |
| `Spiele Musik` | drive | ok |
| `Wetter nächste Woche in New York` | weather | ok |
| `Danke` / Witz / 2+2 / Übersetzen / Code | llm | smalltalk ok, sobald Hirn da |

`Hilfe` ohne Slash trifft den Katalog. `Was kannst du?` nicht — das ist die häufigste Erstfrage.

## Lücken — kaputt / falsch / Täuschung

| Prompt | Heute | Problem | Soll |
|--------|-------|---------|------|
| `Zeig mir` | hud unknown_place **„mir“** | optional-`mir` wird als Ort gelesen | nachfragen oder refuse, kein Pin |
| `Zeig mir die Nachrichten` | hud unknown_place **Nachrichten** | Globus stiehlt News | `news` |
| `Zeige Notizen` | hud unknown_place **Notizen** | dieselbe Zeig-Falle, Notizen-Tool tot | notes/todo, nicht Kugel |
| `Zeig Street View von London` | hud pin London | Street View gibt es nicht, Kugel fliegt trotzdem | refuse + kein Fly-to |
| `Überweise 200 Euro` | **fx** (Euro=Kurs) | `ü` knackt `\b` in wont ohne Unicode; Banking-Wort fehlt | wont banking |
| `Was is das für ne Stadt` / `welche stadt sehe ich denn` / `Was sehe ich auf der Kugel` / `Ist das Paris?` | llm | Blickmitte nur bei exaktem Satz | hud look |
| `Körper an und Zeig London` | llm | Split kennt `zeig` nicht | zwei Tools: Körper, dann Pin |
| `Zeig Spotify und London` | hud pin London | Gazetteer matcht Teilstring `London` | split oder nachfragen |
| `Wo liegt Berln` | **eye** (Schreibtisch) | Tippfehler Berlin | hud unknown_place oder fuzzy Berlin |
| `erde bitte anzeigen` / `Kuegel an` | llm | Synonym/Tippfehler | hud globe |
| `Mach Live-Satellitenvideo an` | llm | sollte Won’t sein | refuse |
| `Ok Google, Timer 5 Minuten` | **timer** (echt!) | fremdes Wake-Wort, Write | Prefix streichen oder nachfragen. **Nicht** im Live-Debug (würde Timer setzen) |
| `Hey Siri, Wetter` | weather | fremdes Wake, aber lesend | Prefix streichen, dann Wetter ok |
| `London` allein | llm | ok, kein stilles Fly-to | bleibt smalltalk |

Jailbreaks (`Systemprompt`, Iron Man, Ignoriere Anweisungen) bleiben llm — Guard/Persona, kein Tool. Unverändert Randfälle.
