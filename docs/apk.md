# Android-APK — `0.16.3`

Optional **Gemini (Google)**. Default bleibt lokal. Das 470-MB-Modell wird **nur geladen**, wenn Gemini aus ist und Sie „Modell starten“ tippen — nicht beim bloßen App-Öffnen.

Bei Gemini: bestes Free-Modell zuerst. Ist das Kontingent leer oder Google überlastet, wechselt Jarvis sofort auf ein kleineres Gemini. Optional **Groq**-Schlüssel als letzter Fallback (viel Free-Nutzung, eigener Key).
