# TEST 18.20 — Tafel, Lage-Layout, Highlights

App-Code **`18.20.0`**. In der App: **Einstellungen → Tests → Spur Heute**.
Jede Box ist ein Satz — einmal tippen, kopieren, in den Chat. Dieselben
Sätze stehen dort als Kopierfeld (Feld antippen oder **Kopieren**).

Der Chat-Schalter auf dem Tablet ist kein Satz. Den Knopf **Chat** /
**Chat zu** in der Lage tippen, nicht eintippen.

## 1. Lage auf dem Tablet

```
Lage an
```

Ab etwa 900 px Breite: die Kugel füllt die Fläche, der Chat rechts ist zu.
Schichten liegen über der Kugel in einer Zeile und lassen sich seitlich
schieben. Die Leiste links sitzt unten in der Seitenleiste.

**Chat** blendet den Chat rechts ein. **Chat zu** blendet ihn wieder aus.
Auf dem Handy gibt es diesen Knopf nicht; dort bleibt die gewohnte
Lage-Ansicht.

## 2. Tischplatte über die Werte-Leiste

Rechts **Tischplatte → an**. Der Schirm wechselt auf die Werkbank, die
Lage geht zu. Derselbe Satz:

```
Tischplatte an
```

## 3. Testprojekt, Sprints, Hintergrund, Quellen

```
Idee: Tik-Tak-To auf der Tischplatte
```

```
Zeig Sprints
```

Sprint 1 trägt den Titel. Leere spätere Karten sagen „Noch leer.“, nicht
„Idee: Felder leer.“

```
Neuer Hintergrund
```

Antwort beginnt mit `Hintergrund:` und nennt das Motiv (Gitter, Pulse
oder Orbit) plus den Akzent. Wand und Akzent wechseln mit, nicht nur der
Name.

```
Zeig Quellen
```

Antwort nennt `Sicht research` und entweder die Quellen oder
`Keine Quellen im Store.` Sie behauptet nicht, es gebe keine Fakten,
während Quellen auf der Tafel stehen.

```
Such Open Source zu Tic-Tac-Toe und plane Sprints für Idee 1
```

Ein Satz, zwei Jobs. Ohne Treffer bleibt die Suche ehrlich leer.
