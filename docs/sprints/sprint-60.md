# Sprint 60 — Homescreen-Widget (`1.10.0`)

| Feld | Wert |
|------|------|
| Status | **CODE** |
| Priorität | **SHOULD** |
| Ziel-Version | **`1.10.0`** |
| Quelle | PO 2026-08-15 |

## Must

| ID | Inhalt | Done wenn |
|----|--------|-----------|
| H1 | Widget auf den Homescreen legen (lange aufs Icon oder Widget-Liste) | Ohne Play Store |
| H2 | Zeigt: nächster Timer oder Erinnerung + eine Wetterzeile (letzter Ort) | Lesbar auf einen Blick |
| H3 | Antippen öffnet Jarvis (Chat oder „Jarvis hören“) | Kein Chat im Widget |
| H4 | Aktualisiert nach Timer/Erinnerung und etwa stündlich das Wetter | Kein Dauer-Tracking |
| H5 | Version `1.10.0` + APK | Sideload |

## Probe

1. Widget setzen → nächster Eintrag sichtbar.
2. Timer stellen → Widget ändert sich.
3. Tippen öffnet die App.

## Won’t

Live-Chat auf dem Widget, Werbung, mehrere Widget-Größen in der ersten Lieferung (eine Größe reicht).
